    変換ルール

    PDF は文書情報と XMP メタデータから著者・タイトル・出版日・掲載誌・DOI を読み取って変換します。XMP を優先し、出版日のない PDF は年なしとして出力します。PDF の作成日・更新日は出版年として使いません。紙面からの推定や OCR は行いません。

    LaTeX の大文字保護・数式を保持し、フィールド名・並び順・波括弧の形式を統一します。journal → journaltitle、address → location、school → institution、year / month → date など、BibTeX の表記を biblatex に寄せます。

    著者・タイトル・出版情報・ページ・DOI・URL・識別子と、アンダーバー（_）で始まる独自フィールドを残します。abstract・keywords・file・note と、crossref・xref・xdata・related などの文献間参照フィールドは削除します。@string は展開し、@preamble は保持します。欠けた情報は補いません。

    引用キーは既存のものも第一著者の姓＋出版年（例：山田2026）に統一します。incollection だけは開始ページを末尾に付けます（例：山田2026p123）。ページが不明なら付けません。著者または出版年が不明なら既存キーを保持し、空欄なら空欄のままにします。

    ファイル名は Year_Authors_Title の形式で、拡張子は付けません。著者は最大3人で、4人以上は et-al を付けます。ファイル名には著者の姓（著者がなければ編者）を使います。日本語の姓名を分けたい場合は「姓, 名」で入力してください。空白とファイル名に使えない文字はハイフンにし、長すぎる名前は UTF-8 で240バイト以内に短縮します。出版年なしは nd、著者なしは Unknown と表示します。
